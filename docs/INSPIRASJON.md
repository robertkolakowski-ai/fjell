# Inspirasjon

| App | Det vi låner |
|---|---|
| Apple Bilder | «Duplikater» med sammenslåing av metadata, personer og steder, nøktern typografi |
| Google Photos / Gemini Photos | Ett-trykks sletteforslag, «Free up space», naturlig språk-søk |
| Slidebox | Swipe-sortering med én hånd, hurtig albumtildeling |
| Clever Cleaner / Photo Cleaner | Kategorier med tydelig «plass du frigjør» |
| Lightroom / Photo Mechanic / Narrative Select | Rask culling, side-om-side, 100 %-zoom på ansikt |
| Aftershoot / FilterPixel / Imagen | AI-culling, lukkede øyne, skarphet |
| digiKam / dupeGuru | Justerbar likhetsterskel, forklaring av hvorfor to filer er like |
| Immich / PhotoPrism | Selvhostet, personvern først, ansiktsgjenkjenning på enheten |
| Cleanup-apper | «3,2 GB frigjort», tydelig «ferdig»-tilstand |

*Bygger på kunnskap om eksisterende apper, ikke på nye nettsøk.*
